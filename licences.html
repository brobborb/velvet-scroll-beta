Open-source software and voices used by Velvet Scroll

Velvet Scroll is free. It is built with the open-source projects below, and the optional natural voices use openly licensed voice models. Each keeps its own licence.

Natural voices (optional)

  • eSpeak NG, which works out how words are pronounced. GNU General Public License, version 3 (full text). Source code: github.com/espeak-ng/espeak-ng.
  • piper-phonemize (Michael Hansen), which connects eSpeak NG to Piper voices, MIT licence: github.com/rhasspy/piper-phonemize. Velvet Scroll uses the unmodified WebAssembly build of eSpeak NG and piper-phonemize published as @diffusionstudio/piper-wasm 1.0.0 (build scripts: github.com/diffusion-studio/piper-wasm).
  • ONNX Runtime Web 1.20.1 (Microsoft), which runs the voice models, MIT licence: github.com/microsoft/onnxruntime.
  • Piper voices from the Piper project (rhasspy/piper-voices, version 1.0.0). Velvet Scroll offers only voices whose model cards list public-domain training recordings: Cori (British English), Linda (LJ Speech), Kristin, John, Norman and Bryce (American English). Voices are downloaded from Hugging Face only when you choose one.

The GNU GPL lets you copy, change and share eSpeak NG. If you would like a copy of the exact eSpeak NG and piper-phonemize source code used by the build above, it is available from the links above, or ask through the project page and we will provide it.
